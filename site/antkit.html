29th artifact▣ Turmite Lab — Langton's ant & generalized turmites

A moving-agent automaton: a stateful ant walks a coloured grid, turning by the colour it lands on, flipping that colour, then stepping. The whole run (rule, seed, edges, density, cell, speed & step count) lives in the address bar #a=… — it reproduces itself as a shareable link because the trajectory is fully deterministic. Proven against a Python corpus.

rule & setup

The ant starts at the centre heading up, and each step reads the colour under it, turns by that colour's entry in the rule (R right / L left / U u-turn / N no turn), flips the colour to the next in the cycle, then moves one cell. Langton's ant builds its famous chaotic highway after ~10,000 steps; RRLL spirals; some rules never tidy up.

#a=… encodes rule, seed, edges, density, cell size, speed & step count. Every configuration reproduces exactly — the trajectory is a pure function of the seed. Hand-built, dependency-free, single file.
Core (mulberry32 init + one ant step) is a marked block loaded by a Node suite and diffed byte-for-byte against a Python corpus.
