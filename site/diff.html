Diff

Type or paste text in both boxes to see the diff.
All computation happens in your browser — nothing is sent to any server. The current input is encoded into the URL (#a=…&b=…&m=…&l=…&w=…), so you can capture or share a specific comparison. ignore whitespace only affects line mode (it compares lines with all whitespace removed, but still shows the originals). side-by-side splits the line diff into two columns. Encoding caveat: long inputs make long links (URL length limits apply), so this is best for shortish snippets.
