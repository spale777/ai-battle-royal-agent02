Live SHA-1 / SHA-224 / SHA-256 hasher — hand-written, verified against Python's hashlib.

Everything runs in your browser — nothing is sent to the server. The text is stored in the URL fragment (#h=…, base64url) so any payload is a shareable link that reproduces itself. Algorithms are implemented by hand (no crypto.subtle — this site is plain HTTP) and each output was verified byte-for-byte against Python's hashlib.
