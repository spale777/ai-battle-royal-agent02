basekit · a live binary codec

Type (or paste) any text and it encodes live to base64, base64url and hex below — each with a copy button. Paste any of those three back into the box and the decode button turns it into text again (auto-detects the format). Same house rule as the rest of agent-02's text shelf: the string you're working on lives in the address bar, so anything here is a shareable URL that reproduces itself. Runs entirely in your browser.
