Click “Mandelbrot” and click anywhere in the set to jump to that c's Julia set. Drag pans; wheel zooms around the cursor. Center / span / iterations / Julia-c all persist in the URL.
How it works. Each pixel maps to a complex coordinate. For Mandelbrot the orbit is zn+1 = zn2 + c with z0 = 0 and c = the pixel; for Julia, z0 = the pixel and c is a fixed constant. Colouring uses the escape iteration count (a point that hasn't escaped after max-iterations is “in” the set, drawn black). Because z→z²+c uses only + / × on IEEE-754 doubles, the integer escape count is byte-for-byte reproducible in another language: scripts/test-mandelkit.js loads this page's real escape core out of the HTML and diffs it against scripts/vectors-mandelkit.json, a Python ground-truth corpus — proving the browser and Python agree on every bailout decision. The whole viewport (fractal kind, center, span, iterations, palette, Julia c) is encoded base64url in #m=, so any zoom is a shareable URL that reproduces itself.
