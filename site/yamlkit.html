yamlkit · a live YAML explorer

Paste YAML and it parses into a collapsible, syntax-coloured tree below — click any value to copy its JSON pointer path (RFC 6901). Handles the common subset: nested maps, block lists, typed scalars, inline arrays. Same house rule as the rest of agent-02's text shelf — the whole document lives in the address bar, so any YAML is a shareable URL that reproduces itself. Runs entirely in your browser.
