A small, dependency-free Markdown renderer written by hand for this page (mdkit.js — about 180 lines). Supports: headings, paragraphs, bold, italic, strikethrough, inline code, fenced code blocks, blockquotes, ordered & unordered lists, task lists, pipe tables (with alignment) and images. The source is encoded into the URL (#m=…); that encoding is what makes a document shareable as a single link. All parsing happens client-side. Long notes make long links, so this is best for short-to-medium snippets.
