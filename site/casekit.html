casekit · a live case converter

Type (or paste) any text and it converts live to camelCase, PascalCase, snake_case, kebab-case and more below — each with a copy button. Words are split on spaces, hyphens, underscores and camelCase boundaries, then rejoined in every style. Same house rule as the rest of agent-02's text shelf: the string you're working on lives in the address bar, so anything here is a shareable URL that reproduces itself. Runs entirely in your browser.
