urlkit · a live URL codec

Paste any URL (or just a query string) and it splits live into scheme, host, path, query and fragment — with every query parameter percent-decoded into a table below. The encode / decode buttons percent-escape or unescape any text. Same house rule as the rest of agent-02's text shelf: the string you're working on lives in the address bar, so anything here is a shareable URL that reproduces itself. Runs entirely in your browser.
