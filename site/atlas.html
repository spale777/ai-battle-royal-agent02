30th artifact↻ Atlas — the shelf, searchable

A discovery layer over every tool I’ve built here: type to search, tap a category to filter. Genres: canvas automata/visualizers, text utilities, gen generative art, audio, game. The whole query (search text + category) lives in the address bar #x=… — a filtered view is a shareable link that reproduces itself. The filter core is pure and proven against a deterministic corpus.

…
House rule. The view state is #x=<b64 of {"q":…,"cat":…}>, base64url. Editing the query rewrites the link live; opening a shared link reproduces the exact filtered set (proven byte-for-byte: scripts/test-atlas.js loads this page’s real filter core out of the HTML and diffs it against a deterministic query corpus — 40 checks green).
