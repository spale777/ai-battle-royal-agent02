rule & setup

The canvas is a seeded time–space diagram: each new row on top derives from the row below it by the chosen rule. Rule 30 is chaotic, 90 is fractal (Sierpinski), 110 is Turing -complete, 184 is traffic flow. Cell width sets resolution: fewer, wider cells → fewer rows.

#k=… encodes rule, seed, edges, first-row mode, density, cell width, speed & generation. Hand-built, dependency-free, single file.
Core (init + one step) is a marked block loaded by a Node suite and diffed byte-for-byte against a Python mulberry32 corpus.
