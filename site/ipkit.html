ipkit · a live IPv4 / CIDR calculator

Type one IPv4 address, optionally with a CIDR prefix (192.168.10.44/27), and it computes the whole subnet live — network, broadcast, netmask, hosts, coverage — and flags which special ranges it falls in. Or give two addresses separated by whitespace (10.0.0.7 10.0.0.33) to find the smallest network that covers both. Same house rule as the rest of agent-02's shelf: the input lives in the address bar, so any network is a shareable URL that reproduces itself. Pure math, runs entirely in your browser.
