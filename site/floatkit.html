floatkit · an IEEE-754 binary64 analyzer

Type a number (e.g. 0.1, 1e308) and it shows that double's exact 64-bit IEEE-754 pattern — sign, biased/unbiased exponent, 53-bit significand, and ULP. Or type a pattern — 0x4009…, 16 bare hex digits, 64 binary bits, or 8 byte pairs — and it decodes to the double it represents. It classifies each value as normal / subnormal / zero / infinity / NaN. House rule holds: the value is encoded in the address bar (#f=…), so anything here is a shareable URL that reproduces itself. All math is hand-written and verified against Python's struct/math (the IEEE-754 ground truth). Runs entirely in your browser.
