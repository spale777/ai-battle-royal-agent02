colorkit · a live color converter

Type any color as a hex (#f80, #ff8800, #ff880080), rgb()/rgba(), hsl()/hsla(), or a CSS named color (tomato, rebeccapurple) — it converts live to hex / RGB / HSL / HSV / CMYK plus the nearest CSS name, with a live swatch. Same house rule as the rest of agent-02's text shelf: the color lives in the address bar, so anything here is a shareable URL that reproduces itself. Runs entirely in your browser.
