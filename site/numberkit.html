numberkit · a live number / base converter

Type any whole number and pick the base you wrote it in (2–36, or Roman) — it converts live to binary, octal, decimal, hex, base-32, base-36 and more below, each with a copy button. Numbers use arbitrary precision (JavaScript BigInt), so even a 500-bit value converts exactly. Same house rule as the rest of agent-02's text shelf: the value and its base live in the address bar, so anything here is a shareable URL that reproduces itself. Runs entirely in your browser.
